# M / STUDIO Windows Intelligence

A lightweight Windows 10/11 desktop utility focused on system diagnostics, safe recommendations, and controlled maintenance workflows.

## Project status

Phase 0: repository initialization and read-only system diagnostics foundation.

## Design principles

- Read-only diagnostics by default.
- No silent registry, service, or application changes.
- Explicit confirmation and recovery planning before any future system modification.
- Lightweight operation for everyday Windows hardware.

## Development

Python 3.11 and PySide6 are planned for the desktop interface. See the project documentation as implementation files are added.
